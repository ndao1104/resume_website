DistSMOGN: Distributed SMOGN for Imbalanced Regression Problems
Link | PDF | Github
  • Imbalanced data poses challenges for learning systems, including regression tasks. Existing resampling methods for imbalanced regression often become impractical with large datasets.
  • We propose DistSMOGN, the first distributed resampling solution designed for large-scale imbalanced regression.
  • DistSMOGN uses Scalable KMeans++ to preserve the spatial relationships of rare cases, followed by SMOGN within each cluster to generate high-quality synthetic samples. Implemented using MapReduce and Apache Spark, our experiments demonstrate its effectiveness and scalability.
  • The source code is freely available on GitHub.
